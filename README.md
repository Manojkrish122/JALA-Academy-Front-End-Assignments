## 📌 Project Overview
This repository contains production-ready, fully commented, and accessible implementations for **all 15 assignment PDFs** assigned by the **JALA Academy Placement Team**. 

Every question from each assignment PDF has been systematically answered, structured into modular standalone web pages, and unified under a **Central Interactive Showcase Portal (`index.html`)**. In addition, a comprehensive technical interview preparation guide (**[`INTERVIEW_PREP.md`](INTERVIEW_PREP.md)**) provides answers to every *"Good to know"* and *"Things to know"* topic to ensure interview success.

## 💻 How to Run & Preview Locally

### Option 1: Direct Browser Launch
Simply double-click **`index.html`** in File Explorer, or right-click &rarr; **Open with** &rarr; **Google Chrome** (or Edge/Firefox). All 15 assignments can be explored directly from the portal!

### Option 2: Using VS Code Live Server / Local Web Server
If you have Python or Node installed, you can launch a local web server from this directory:

```bash
# Using Python 3
python -m http.server 8080

# Or using Node.js 'serve' or 'live-server'
npx serve .
```
Then navigate to: **`http://localhost:8080/index.html`**

## 📤 Step-by-Step Guide to Publish on GitHub / Bitbucket

To share this complete assignment repository with the JALA Placement Team, follow these simple steps:

### Step 1: Initialize Git in this Directory
Open PowerShell or your terminal in this directory:
```bash
git init
git add .
git commit -m "feat: complete JALA Academy front-end UI assignments (HTML5, CSS3, JS, AngularJS)"
```

### Step 2: Create a New Public Repository
1. Log in to [GitHub](https://github.com/new) (or Bitbucket).
2. Create a new repository named `JALA-Academy-Front-End-Assignments`.
3. Set the visibility to **Public**.
4. Leave *"Initialize this repository with a README"* **unchecked** (we already have a complete one).

### Step 3: Link & Push Your Code
```bash
# Rename default branch to main
git branch -M main

# Add your repository remote URL (replace with your actual GitHub URL)
git remote add origin https://github.com/<your-username>/JALA-Academy-Front-End-Assignments.git

# Push all files at once
git push -u origin main
```

### Step 4: Submit Your Repository Link
Copy your public repository URL:
`https://github.com/<your-username>/JALA-Academy-Front-End-Assignments`
and share it with the **JALA Placement Team**!
