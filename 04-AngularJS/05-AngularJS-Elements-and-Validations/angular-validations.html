Things to Know: Animations & Routing in AngularJS

  • How ngAnimate Works: AngularJS automatically appends and removes CSS classes during lifecycle changes:
    • .ng-hide-add: Added when an element is starting to hide.
    • .ng-hide-add-active: Triggered for the active transition phase.
    • .ng-hide-remove: Added when an element is starting to show.
    • .ng-hide-remove-active: Triggered to complete the expansion.
  • How ngRoute Works: The $routeProvider service monitors changes in the browser URL hash fragment (#/... or #!/...). It dynamically fetches the designated templateUrl and injects it into the <div ng-view></div> container without reloading the page.
  • Role of otherwise(): .otherwise({ redirectTo: '/home' }) functions as a catch-all route handler, safely redirecting broken or unrecognized URLs back to the default route.
