Things to Know: Filters and Angular APIs

  • What is a Filter? A filter formats the value of an expression for display to the user without changing the source value in the Model. Filters can be applied in templates via pipe syntax ({{ expression | filterName:arg1:arg2 }}) or injected as dependencies in controllers (e.g. $filter('currency')(value)).
  • Built-in Filters: currency, date, filter, json, limitTo, lowercase, number, orderBy, uppercase.
  • Angular Global API: Utility functions exposed on the global angular namespace that replace utility libraries like lodash for fundamental tasks: angular.copy() (deep cloning), angular.element() (jqLite DOM wrapper), angular.equals() (deep comparison), angular.forEach(), angular.fromJson() / angular.toJson().
