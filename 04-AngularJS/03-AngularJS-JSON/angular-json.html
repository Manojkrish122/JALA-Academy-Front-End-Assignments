2. Spotting the Difference: ng-options vs ng-repeat in <select>

Explore how AngularJS handles select dropdowns through ng-options vs manual <option ng-repeat>:

A. Modern ng-options (Object Binding)

• Bound Model: selectedOptionObject • Value in Scope: {{ selectedOptionObject | json }}

B. Traditional <option ng-repeat> (String Binding)

• Bound Model: selectedRepeatValue • Value in Scope: "{{ selectedRepeatValue }}" (String Only)
Key Difference: ng-options binds directly to the entire rich JavaScript Object (including id, level, and track properties), whereas ng-repeat in select options natively converts the value into a plain string.

Things to Know: Understanding the Concept of JSON

  • What is JSON? JSON (JavaScript Object Notation) is a lightweight, human-readable, language-independent data interchange format derived from JavaScript object syntax.
  • Syntax Rules:
    • Data is represented in key/value pairs (keys must always be wrapped in double quotes: "key": "value").
    • Data items are separated by commas (no trailing comma after the last item).
    • Curly braces {} hold objects; square brackets [] hold arrays.
  • Supported Data Types: String (double-quoted), Number, Object, Array, Boolean (`true`/`false`), and `null`. (Functions and `undefined` are not permitted).
  • AngularJS & JSON: AngularJS seamlessly parses JSON HTTP responses into native JS objects, and provides the json filter ({{ data | json }}) for real-time debugging inspection.
