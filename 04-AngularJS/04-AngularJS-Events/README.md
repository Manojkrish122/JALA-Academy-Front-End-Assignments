# AngularJS Events, DOM Manipulation & MySQL Pipeline

## Overview
This module demonstrates how an enterprise single-page application orchestrates full-stack data ingestion from a MySQL relational database via a backend REST API, controls Document Object Model (DOM) rendering states (`ng-show`, `ng-hide`, `ng-disabled`), and handles user interactions using `ng-click`, `ng-mousemove`, and `$event`.

## PDF Assignment Requirements & Implementation

### 1. Ingesting Data from MySQL to AngularJS
- **Architecture**:
  - `database-sample.sql`: Defines MySQL schema and table rows.
  - `backend-mock.php`: Server-side endpoint performing `SELECT` queries on MySQL and outputting JSON.
  - `app.js`: Ingests endpoint data via `$http.get()`, populating `$scope.mysqlStudents` with mock fallback for standalone client previewing.

### 2. Document Object Model & Directives
- **DOM**: The browser's object-tree representation of the parsed HTML document.
- `ng-show`: Displays the DOM element only when the expression evaluates to truthy (adds `.ng-hide` CSS rule when falsy).
- `ng-hide`: Hides the element when truthy.
- `ng-disabled`: Programmatically activates or deactivates form buttons and controls based on Boolean model state.

### 3. Events (`ng-click`, `ng-mousemove`, `$event`)
- `ng-click`: Increments counters and captures event payload.
- `ng-mousemove`: Tracks real-time mouse pointer coordinates (`offsetX`, `offsetY`) across an interactive canvas.
- `$event`: The native browser event object passed to AngularJS controller methods, providing client coordinates, modifier keys (`shiftKey`, `altKey`), and target DOM elements.

## Interview Questions & "Things to Know"

### Q1: What is MySQL?
- MySQL is a leading open-source Relational Database Management System (RDBMS) developed by Oracle.
- It stores data in relational tables with primary and foreign keys.
- Client-side frameworks like AngularJS, Angular, and React **never connect directly to MySQL**. Instead, requests travel over HTTP/HTTPS to an API gateway (Node, PHP, Spring Boot, Python), which authenticates and executes queries on MySQL before returning JSON payloads to the front-end.

### Q2: What is an Event?
- An event represents a physical or system signal generated by the user or browser environment (mouse clicks, typing, window resizing, page scroll, asynchronous responses).
- In standard JavaScript: Handled via `addEventListener('event', callback)`.
- In AngularJS: Handled declaratively via directives (`ng-click`, `ng-mousemove`, `ng-change`) which integrate seamlessly with `$apply()` and dirty-checking cycles.
