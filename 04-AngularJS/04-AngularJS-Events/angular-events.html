Things to Know: MySQL and Events

  • What is MySQL? MySQL is an open-source Relational Database Management System (RDBMS) that stores structured data into organized tables consisting of rows and columns. It uses Structured Query Language (SQL) for CRUD (Create, Read, Update, Delete) transactions and ensures ACID properties for data integrity.
  • What is an Event? An event is an action or occurrence that takes place in the browser (e.g. user clicks a button, moves the mouse, presses a key, submits a form, or an image finishes loading). The browser issues an Event Object that can be captured and handled by event listener functions.
  • AngularJS Event Directives: ng-click, ng-dblclick, ng-mousedown, ng-mouseup, ng-mouseenter, ng-mouseleave, ng-mousemove, ng-keydown, ng-keyup, ng-change, ng-submit.
