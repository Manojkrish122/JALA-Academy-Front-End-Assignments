Things to Know (CSS Page Adjustments)

  1. Difference between visibility:hidden and display:none: visibility: hidden hides the element visually, but the element still takes up layout space and affects the page flow. display: none removes the element completely from document layout flow as if it never existed (takes 0px space).
  2. Difference between inline and block-level elements: Block elements (e.g. <div>, <p>) start on a new line and expand to full width. Inline elements (e.g. <span>, <a>) flow within lines and ignore vertical margin/height.
  3. What are selectors? CSS Selectors target HTML elements to apply rules (Universal *, Type p, Class .btn, ID #top, Attribute [type="text"], Pseudo-class :hover).
  4. Which property is used to set the line style for the outline? The property is outline-style (options: solid, dashed, dotted, double, groove, etc.).
