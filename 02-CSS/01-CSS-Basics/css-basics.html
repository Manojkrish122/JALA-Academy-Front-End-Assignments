Parallax Effect: Fixed Background

This container has a background image set to background-attachment: fixed;, background-size: cover;, and background-position: center;. As you scroll the page, the image stays fixed in place while content flows smoothly above it!

3. Multi-Pattern Four-Sided Borders

The box below has unique width, style, and color defined for all 4 borders:

Top Border: 6px SOLID #e63946 (Crimson Solid)
Right Border: 8px DASHED #2a9d8f (Teal Dashed)
Bottom Border: 10px DOUBLE #e76f51 (Coral Double)
Left Border: 7px DOTTED #1d3557 (Navy Dotted)
CSS Definition:
border-top: 6px solid #e63946;
border-right: 8px dashed #2a9d8f;
border-bottom: 10px double #e76f51;
border-left: 7px dotted #1d3557;

4. Dimensions: Height & Width in Pixels (px) vs Percentages (%)

Parent Container: width: 100%; height: 350px;

Fixed Pixels (px)

width: 240px;

height: 140px;

Rigid, does not resize with parent.

Fluid Percentage (%)

width: 50%;

height: 70%;

Dynamic, scales proportionally to parent container.

Justified Text Alignment

text-align: justify | color: #2d3748 | font-size: 1rem

Justified text aligns evenly along both left and right margins, adding space between words as necessary. It creates a neat, clean newspaper-style column edge that looks balanced across magazine-style article cards.

Key Interview Concepts (Things to Know)

  • 1. Importance of HTML DOCTYPE: Informs the browser about the HTML standard version being used (HTML5: <!DOCTYPE html>). It prevents browsers from falling into "Quirks Mode" and ensures standard compliant rendering.
  • 2. Linking External CSS: <link rel="stylesheet" type="text/css" href="style.css"> inside the <head> element.
