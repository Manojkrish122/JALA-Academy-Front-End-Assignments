Things to Know (CSS Compatibility & Tables)

  • 1. Table Structure: A complete semantic table includes <table>, <caption>, <thead> (header rows), <tbody> (data rows), <tfoot> (summary rows), <tr> (row), <th> (header cell), and <td> (data cell).
  • 2. Cell Padding vs Cell Spacing:
    • Cell Padding: The internal space between cell borders and cell contents (styled with padding: 10px; on td/th).
    • Cell Spacing: The external space between adjacent individual table cells (styled with border-spacing: 5px; on the table element, or removed via border-collapse: collapse;).
  • 3. What are Form Attributes? Key HTML form attributes include:
    • action: Destination URL where data is transmitted on submission.
    • method: HTTP method used (GET for search/idempotent queries, POST for sensitive/state-modifying payloads).
    • enctype: Encoding type (e.g. multipart/form-data for file uploads, application/x-www-form-urlencoded for standard fields).
    • target: Window or frame where response is rendered (_blank, _self).
    • autocomplete: Enables or disables browser auto-completion (on / off).
    • novalidate: Bypasses default HTML5 browser validation to permit custom JS validation.
