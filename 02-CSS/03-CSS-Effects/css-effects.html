Things to Know (CSS Effects)

  • 1. Understanding Position Properties:
    • static: Normal document flow (default). Top/Right/Bottom/Left have no effect.
    • relative: Positioned relative to its normal position without taking it out of flow.
    • absolute: Positioned relative to its nearest non-static positioned ancestor. Removed from document flow.
    • fixed: Positioned relative to the browser viewport window; stays fixed during scrolling.
    • sticky: Toggles between relative and fixed depending on scroll offset.
  • 2. What is a Box Model? The CSS box model is a container that wraps every HTML element consisting of: Content (actual text/image) → Padding (clear area around content) → Border (border around padding) → Margin (clears area outside border). box-sizing: border-box includes padding and border in the element's total specified width and height.
