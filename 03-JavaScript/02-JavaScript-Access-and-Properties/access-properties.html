Things to Know: Keywords and Built-in Functions of JavaScript

Essential knowledge for front-end technical interviews:

  • Reserved Keywords: Words reserved by JavaScript syntax that cannot be used as variable names (e.g. function, class, return, this, typeof, instanceof, async, await, try, catch, const, let, var, new, super).
  • Built-in Global Functions: Functions available on the global scope (e.g. parseInt(), parseFloat(), isNaN(), isFinite(), encodeURI(), decodeURI()).
  • Standard Built-in Objects: Native standard objects providing utility methods:
    • Math (e.g. Math.max(), Math.random(), Math.floor())
    • Date (e.g. Date.now(), toISOString())
    • JSON (e.g. JSON.stringify(), JSON.parse())
    • Array (e.g. map(), filter(), reduce(), sort())
    • Object (e.g. Object.keys(), Object.assign(), Object.freeze())
