Things to Know: How JavaScript Differs from Java?

Despite similar names, Java and JavaScript are two completely distinct languages developed for different paradigms:

Criteria JavaScript (JS) Java
Type System Dynamically typed (types resolved at runtime) Statically typed (types declared & checked at compile time)
Execution Interpreted / JIT compiled by V8, SpiderMonkey Compiled to bytecode executed on Java Virtual Machine (JVM)
Object Model Prototype-based inheritance Class-based object-oriented programming
Concurrency Single-threaded with asynchronous Event Loop Multi-threaded with thread pooling & synchronization
Primary Domain Web browser interactivity, Node.js server backends Enterprise backend services, Android apps, large distributed systems
