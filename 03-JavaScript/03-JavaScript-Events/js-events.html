Things to Know (JavaScript Debugging & Cookies)

  • 1. Debugging in JavaScript:
    • Console APIs: console.log(), console.error(), console.warn(), console.table(), console.time()/console.timeEnd().
    • Debugger Statement: Placing debugger; in code automatically pauses execution in browser DevTools.
    • DevTools Breakpoints: Line-of-code breakpoints, conditional breakpoints, DOM mutation breakpoints, and XHR/fetch breakpoints.
    • Call Stack & Scope Inspection: Inspecting local, closure, and global variable values in real-time.
  • 2. What are Cookies?
    • Small key-value text pairs (max ~4 KB) stored by the web browser on the client machine.
    • Transmitted to the server automatically with every subsequent HTTP request within the same domain.
    • Attributes: expires/max-age, path, domain, Secure (HTTPS only), SameSite (CSRF protection), and HttpOnly (prevents client-side JS read for sensitive auth tokens).
